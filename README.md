# Zoo Digital

* Aluno: Luis Eduardo Brescansin Canal

Projeto desenvolvido em Java utilizando Maven para a disciplina de Organização e Abstração na Programação.

## Descrição

O Zoo Digital é uma aplicação de linha de comando (CLI) que permite cadastrar e gerenciar diferentes tipos de animais, aplicando conceitos fundamentais de orientação a objetos como:

- Herança
- Polimorfismo
- Abstração
- Encapsulamento
- Interfaces
- Casting com `instanceof`
- Métodos e atributos `static`
